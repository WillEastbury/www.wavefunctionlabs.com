How a Transformer Produces One Word

What you type becomes numbers
“The capital of France is”
↓
Tokenizer

Break the sentence into small reusable pieces, then swap each piece for a dictionary number. The model never reads letters directly after this point. It only sees the numbered pieces that came out of this first lookup stage.

→ ch2
↓
Embedding Lookup

Use each number as an address into a giant table and copy out one row of stored values. Every input piece gets its own row, so the sentence becomes a short stack of numeric strips ready for the main loop.

→ ch3
↓
Position Stamp

Add a location tag to every row so first, second, third, and later pieces are treated differently. Without this stamp, the same rows could be shuffled around and the model would lose the order of the sentence.

The thinking loop
× 32 Layers
↓
Normalise

Rescale the current numbers so no row grows too hot or too faint before the next operation. This keeps the running state steady and makes later comparisons more reliable from layer to layer.

→ ch7
↓
Attention

For each word position, look back across the earlier words and decide what matters most right now. The result is a fresh summary row that blends in the most relevant earlier clues without rereading the original text.

→ ch6
↓
+ Add Back (Residual)

Keep the old running state and add the new update on top of it. This lets the layer improve what it knows without throwing away the useful structure that was already carried forward.

→ ch5
↓
Normalise (Again)

Rescale once more before the next transform. This second reset stops values from drifting as the stack gets deeper and helps each layer start from a calm, consistent numeric range.

→ ch7
↓
Feed-Forward

Now each word row is processed on its own. The layer expands it, filters it, and compresses it again so rough patterns become sharper choices about what that word position should carry into the next stage.

→ ch8
↓
+ Add Back (Residual)

Blend this second update back into the running state as well. The model keeps a durable trail of everything learned so far, then hands that richer state to the next layer and repeats the same loop.

→ ch5
Choosing the next word
↓
Final Normalise

Give the finished row one last rescale before turning it into word scores. This final cleanup keeps the handoff tidy so the chooser at the end reads a stable, well-shaped result.

→ ch7
↓
Score Every Word in the Dictionary

Compare the finished row against every possible next word the model knows. About 128,000 candidates each get a score, and higher scores mean the model sees a better fit for what should come next.

→ ch9
↓
Pick One

Turn the scores into a final choice. Temperature, top-k, and top-p adjust how adventurous the pick can be, then one candidate wins and is emitted as the next piece of text.

Prefill vs Decode

Prefill

Process the whole prompt in one pass, from the first word to the last. This fills the memory cache with the reusable history the model will lean on for every later output step.

Decode

Generate one new word at a time after that first pass. Reuse the cached history, add one fresh result, then loop again until the answer is complete.
